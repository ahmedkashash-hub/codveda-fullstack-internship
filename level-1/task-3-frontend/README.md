# Level 1 — Task 3: HTML/CSS/JavaScript Frontend

A responsive static product showcase that fetches products from the Level 1 Task 2 Express API and renders product cards dynamically.

## Run and verify

1. Start `level-1/task-2-rest-api` with `npm install` and `npm start`.
2. Serve this directory, for example with `npx serve .`.
3. Open the displayed URL and confirm the loading message becomes a product count and cards.
4. Stop the API and refresh to verify the unavailable state.
5. Resize below 700 px to verify the single-column responsive layout.

The project uses plain HTML, CSS, browser JavaScript, and `fetch`; it has no build step.
